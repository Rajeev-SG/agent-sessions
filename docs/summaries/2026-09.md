# September 2026

- Pi/OMP session discovery and parsing now accept the current on-disk shape, where a padded `title` record precedes the `session` header. Both `PiSessionDiscovery` and both `PiSessionParser` load guards previously read only the first record, so sessions from current OMP builds were invisible in the app. The fix keeps the scan bounded (at most four records, 32 KiB) and strict: only recognized `title` records may precede the header, malformed or unrelated prefixes still reject the file, and legacy session-first files behave exactly as before. Seven focused tests cover title-first discovery, session-first compatibility, rejection of unrelated/malformed/oversized prefixes, and bounded-scan behavior.
